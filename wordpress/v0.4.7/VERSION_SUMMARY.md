# WordPress v0.4.7 - Version Summary

## What changed

- The **Bordereau description** settings (order number / product names) now also apply to parcels that were already sent. Generating the bordereau first updates the parcel's description at Intigo (only possible while the parcel is awaiting pickup); if Intigo refuses, the bordereau is generated as before.

_Your Intigo settings are kept when updating._
