# WordPress v0.4.6 - Version Summary

## What changed

### Choose what the bordereau description prints

- New **Bordereau description** card in **Settings** with two switches: **Order number** and **Product names**.
- Turn off **Product names** for merchants whose customers do not want the products shown under "Description du produit" / "Commentaire" on the bordereau.
- If both are off, the order number is still sent (Intigo requires a description).
- Both switches are on by default: nothing changes for existing stores.
- French and Arabic translations included.

_Your Intigo settings are kept when updating._
