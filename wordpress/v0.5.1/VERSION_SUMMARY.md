# WordPress v0.5.1 - Version Summary

## What changed

### Manage Orders

- **Address-issue filter**: new **Show** menu — All orders, Address issues, To check, Incomplete, Not detected — each with its count. Lists orders not sent to Intigo yet.
- **Orders per page**: choose 10, 30, 50 or 100. Each user keeps their own choice.
- **You stay on the same page after an action**: editing, sending, confirming, detecting or resetting an order on page 3 brings you back to page 3 (same filter and page size) instead of page 1.
- French and Arabic translations included.

_Your Intigo settings are kept when updating._
